# Docker Get Started - 123103132

**Guide:** Containerize a Node.js application

## Langkah yang dikerjakan
1. Clone sample app docker-nodejs-sample
2. Jalankan docker init untuk membuat Dockerfile, .dockerignore, dan README.Docker.md
3. Perbaiki perintah start di Dockerfile menjadi node src/index.js
4. Build dan jalankan dengan docker compose up --build
5. Aplikasi dapat diakses di http://localhost:3000
